# Secrets checklist — Matou/matou-app

Generated by `factory onboard` (#572). Two delivery paths, never mixed for
the same value (2026-07-11 breach vector — env vars land in
`docker inspect .Config.Env`, readable by anyone with Docker API access):

## `.sandcastle/.env` — ONE key only

```
CLAUDE_CODE_OAUTH_TOKEN=
```

Nothing else goes in this file. It's forwarded into the sandbox as a
`docker run -e` value, which is exactly the exposure the other tokens avoid
by shipping as files instead — `CLAUDE_CODE_OAUTH_TOKEN` is the one
exception because the `claude` CLI has no file-based flag for it.

## `.sandcastle/secrets/*` — bearer tokens as read-only files, git-ignored

| File | Consumed by | Needed if |
| --- | --- | --- |
| `forgejo_token` | `list-ready-tasks.sh`, `preflight-triage.sh`, tracker calls in `prompt.md` | always |
| `mattermost_bot_token` | `ask-human.sh`, `notify-mattermost.sh` | this repo asks humans mid-task or posts run notifications |
| `digitalocean_access_token` | `clan-lab`-style skills (doctl) | this repo's swarm tasks touch live droplet infra |
| `ourcloud_lab_dns_token`-equivalent | any DNS-touching skill | this repo has a lab-DNS analog |

Any file can be omitted — each consumer only fails if it actually needs the
token that's missing. For CI, `run-swarm.sh` materializes these files from
Forgejo org Actions secrets at the start of every run (nothing to do). For a
manual host run:

```sh
install -m 0600 /dev/stdin .sandcastle/secrets/forgejo_token <<< "$FORGEJO_TOKEN"
install -m 0600 /dev/stdin .sandcastle/secrets/mattermost_bot_token <<< "$MATTERMOST_BOT_TOKEN"
```

## Org Actions secrets this repo's workflows expect

`SWARM_FORGEJO_TOKEN`, `CLAUDE_CODE_OAUTH_TOKEN` (+ optional
`CLAUDE_CODE_OAUTH_TOKEN_B` failover), `MATTERMOST_URL`,
`MATTERMOST_BOT_TOKEN`, `MATTERMOST_CHANNEL_ID`, and
`DIGITALOCEAN_ACCESS_TOKEN` if this repo's tasks touch clan-lab infra. Org
secrets are shared across every factory-driven repo already — nothing to
mint per-repo unless this repo needs a token none of the others use.
